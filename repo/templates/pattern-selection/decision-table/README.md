# pattern-selection/decision-table

- Corresponding template: 10.2 Pattern Decision Table, 10.3 Filling-In Process Checklist
- One-sentence purpose: Turn 10.2's six patterns × five criteria into a fillable table for each intervention point, and use a prompt to generate a candidate intervention point table from a workflow step list
- File list:

| File | What it is | How to use |
|------|--------|--------|
| `decision-table.md` | Fillable six-pattern × five-criteria decision table (with the three preconditions and a conclusion section) | Copy one for each AI intervention point and fill it in; not one per project |
| `prompt-intervention-points.md` | A prompt that generates the "intervention point list" | Send it to any LLM together with your workflow step list to produce a candidate intervention point table; the candidates are only a starting point, only running each one through the decision table makes it count |
