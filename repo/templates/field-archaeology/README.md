# field-archaeology

Corresponding template: Template 6, Field Archaeology Kit (companion: Chapter 6) ([full appendix](../../../docs/appendices/template-06-field-archaeology.md)).
Purpose: a fillable structured template for the friction log, plus an AI prompt that organizes spoken notes or scratch notes into a structured log.

| File | What it is | How to use |
|------|--------|--------|
| `friction-log.md` | The Template 6.2 fillable friction log (with the four-way type split and recording rules) | Print it out for shadowing and jot notes on the spot; fill it in completely within 24 hours |
| `prompt-organize.md` | AI organizing prompt, the three steps transcribe → structure → cluster | Send it along with your transcript to any model |
