# premortem, Pre-mortem Memo

Corresponding template: Template 4, Deployment Charter and Pre-mortem Memo, sections 4.3–4.6, the Pre-mortem part (companion: Chapter 1) ([full appendix](../../../docs/appendices/template-04-deployment-charter.md)).
Purpose: at project kickoff, spend 15–30 minutes writing a memo on the five most likely ways the project dies. Pair each cause of death with a defense and an owner.

| File | What it is | How to use |
|------|--------|--------|
| premortem-template.md | The Template 4.4 fillable memo plus the Template 4.5 rules checklist | Copy it, fill in each item, send the finished memo to the sponsor |
| prompt-premortem.md | The pre-mortem facilitation prompt (built from the Template 4.3 method and the Template 4.6 reference library of common ways to die) | Paste it into an AI chat for guided facilitation; it produces a draft in Template 4.4 format |

The example text comes from the book's Anchor & Helm case.
