# field-mvp, Field MVP Pack Scaffold

Corresponding template: Template 0, Field MVP Pack (companion: Chapter 0) ([full appendix](../../../docs/appendices/template-00-field-mvp-pack.md)).
Purpose: the five fillable templates for the two-hour Field MVP (used in order 0.1–0.5), plus two AI prompts.

| File | What it is | How to use |
|------|--------|--------|
| workflow-claim.md | The Template 0.1 fillable workflow claim | Copy it, fill in the two blanks, pass the three self-check items |
| case-table.md | The Template 0.2 case table skeleton (10 rows) | Copy it, fill in 10 cases following the case selection rules |
| action-queue.md | The Template 0.3 action queue prototype table | Copy it into any spreadsheet tool, do not spend more than 25 minutes on it |
| scoring-table.md | The Template 0.4 real-user scoring sheet | Read the four-grade definitions aloud before scoring, record the user's own words for each line |
| readout-memo.md | The Template 0.5 readout memo skeleton (with the Template 0.6 red line declaration as an appendix note) | Write it as one page when the MVP ends, answer first |
| prompt-workflow-claim.md | Prompt: raw ask conversation to claim candidates | Paste in a de-identified conversation transcript, take a candidate, then run your own self-check |
| prompt-case-table.md | Prompt: de-identified sample data to a case table draft | Paste in de-identified data plus the claim, then check the draft by hand line by line |

The example text comes from the book's Anchor & Helm case.
